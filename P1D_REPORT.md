## Why P1d stopped

- **D5 LOACO (grouped_random) has 0 feasible folds.** A4.5 requires D5 LOACO and gate G3 criterion (b) is computed on it, so G3 cannot be evaluated as frozen. Every attack class with ≥ 200 training windows is absent from the grouped_random test split (table below): D5 has only 42 one-hour groups (5 working days) and each attack class occupies a few hours, so the shuffled 60/20/20 group split places each class wholly in one split.
- D5 natural_novelty is feasible: test-only classes ddos, portscan ({'ddos': 6639, 'portscan': 1335} test windows); train-tail validation holds 26 attack windows ({'dos_slowloris': 4, 'heartbleed': 22}) and 9182 benign windows, giving a 130 + 26 validation set.
- The remaining A4.5 evaluations (D5 natural_novelty, D3 LOACO with 10 detectors, D3 natural_novelty Wilkie) were not run: without D5 LOACO the frozen gate cannot decide, and running them first would expose results before an author decision on D5 LOACO.
